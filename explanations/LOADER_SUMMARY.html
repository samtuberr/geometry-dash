קובץ צורך תוכן

segments.json עדיפות ראשונה triangle_segment_ids — לכל משולש מספר סגמנט

segmented.ply אופציונלי לא משמש הלודר (רק לבדיקה וויזואלית)

🚀 מה הלודר עושה

  1. קורא את קבצי JSON/CSV מתיקיה אחת (למשל mesh_06)
  2. מקבץ את המשולשים לפי segment_id
  3. מחשב קודקודים משודרגים — רק הקודקודים שהסגמנט משתמש בהם (לא כל הקודקודים של המש)
  4. מחשב שטח וגם נורמל לכל משולש
  5. מחזיר NumPy arrays שמוכנים לשימוש בפיטינג וסיווג

💾 מבנה של SegmentRecord

SegmentRecord( mesh_id: str # 'mesh_01', 'mesh_02', ... segment_id: int # 0, 1, 2, ... triangle_ids: np.ndarray # (T,) — מס' המשולש המקורי points: np.ndarray # (V, 3) float64 triangles: np.ndarray # (T, 3) int64 — אינדקסים ל-points triangle_areas: np.ndarray # (T,) triangle_normals: np.ndarray # (T, 3) — וקטורי יחידה )
