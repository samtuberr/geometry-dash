🎯 The classifier stage

The final decision: a supported primitive, or unresolved?

📋 What does this stage do?

This stage takes all the refined candidates from refinement.py and decides:

  • Which primitive type? plane, cylinder, cone, sphere, torus
  • Or does nothing fit? unresolved (freeform, unsupported, poor fit)
  • How sure are we? a confidence score between 0 and 1
💡 Guiding principle: a candidate is accepted only if it meets every criterion. If several candidates pass, the simplest one wins, unless a more complex candidate explains the normals much better.

🔄 The decision flow

Step 1: compute the normal tolerance → Step 2: evaluate every candidate → Step 3: keep the ones that pass → Step 4: choose the winner
┌─────────────────────────────────────────────────────────────────┐ │ For every segment: │ │ ┌──────────────┐ │ │ │ Refinements │ ──► plane, cylinder, cone, sphere, torus │ │ └──────────────┘ (whatever could be computed) │ │ │ │ │ ▼ │ │ ┌──────────────────────────────────────────┐ │ │ │ Check every candidate: │ │ │ │ • vertex residuals ≤ tolerance? │ │ │ │ • normal residuals ≤ tolerance? │ │ │ │ • enough vertices? │ │ │ │ • plausible radius? │ │ │ └──────────────────────────────────────────┘ │ │ │ │ │ ┌────┴────┐ │ │ ▼ ▼ │ │ [pass] [fail] │ │ │ │ │ │ ▼ ▼ │ │ choose if nothing passes │ │ the ─► unresolved │ │ simplest (keep the closest one for the report, │ │ then run the quadric diagnostic) │ └─────────────────────────────────────────────────────────────────┘

📏 The acceptance criteria

1. Position residuals

Every vertex must be close to the candidate surface:

RMS(distances) / scale ≤ 0.001
MAX(distance) / scale ≤ 0.01

Here scale is the RMS distance from the centre, a typical size of the segment. So the average deviation must be less than a thousandth of the segment's size.

2. Normal residuals

⚠️ Why are normals necessary?
Vertices alone are not enough! Two rings of a coarse cylinder also lie exactly on a sphere. Only the normals tell them apart.

The angle between the facet normal and the surface normal must be small:

RMS(angles) ≤ normal_tolerance

What is the tolerance? It depends on the segment's tessellation:

normal_tolerance = max(0.5°, 0.5 × max_dihedral_angle)

max_dihedral_angle is the largest angle between the normals of two triangles that share an edge. On a cylinder with 32 sides the dihedral angle is 11.25°, so the tolerance is 5.6°. This avoids rejecting legitimate primitives just because their tessellation is coarse.

3. Minimum number of vertices

Type Degrees of freedom Minimum vertices
plane33 (no extra requirement)
sphere47
cylinder58
cone69
torus710

The reason: a fit is only meaningful with more measurements (vertices) than parameters.

4. Plausible radius

radius ≤ 1000 × scale

A "sphere" whose radius is a million times the segment's size is really a plane. If the radius is too large, the candidate is rejected.

🏆 Choosing the winner: simplicity wins

If several candidates pass every criterion, how do we choose?

Basic rule: the simplest wins!
plane < sphere < cylinder < cone < torus

A plane is always preferred to a sphere (a plane is a sphere with infinite radius). A cylinder is preferred to a cone (a cylinder is a cone with a zero angle).

Exception: a more complex candidate that explains the data better

A more complex candidate replaces the simpler one only if:

complex.normal_error < 0.8 × simple.normal_error
AND
improvement > 0.005°

That is: it must reduce the normal error by at least 20% and also by at least 0.005 degrees.

Who counts as a "rival" and who does not?

Type Contains as a limit case Not a real rival
plane—sphere, cylinder, cone, torus
sphereplane (r→∞)torus
cylinderplane (r→∞)cone, torus
coneplane, cylinder—
torussphere, cylinder—

When a cylinder passes, a cone probably passes too (with an angle close to zero). That is not a real rival, because it is the same surface.

🥚 Quadric diagnostic for rejected segments

When no candidate is accepted, the segment is unresolved. So that the reason explains what the surface is, quadric.py fits a general quadric to the vertices:

xᵀ A x + b · x + d = 0 (10 coefficients, the smallest singular vector)

The fit is scored by the Sampson distance |Q(x)| / |∇Q(x)|, a first-order approximation of the geometric distance. It is therefore in the same relative units as the primitive residuals and is checked against the same tolerance (1e-3).

  • The quadric fits: the eigenvalues of A give its kind (ellipsoid, hyperboloid of one or two sheets, non-central quadric). For an ellipsoid the semi-axes and the centre are reported too.
  • No quadric fits: the reason says the surface is freeform.
⚠️ The diagnostic only explains. It never turns a segment into a primitive, because arbitrary quadrics are outside the types the assignment supports.

📊 Computing the confidence

⚠️ This is not a probability!
The confidence is a heuristic score between 0 and 1, not a calibrated probability.

For an accepted primitive:

confidence = position_margin × evidence × separation position_margin = clip(-log10(position_ratio) / 3, 0, 1) (position_ratio = the worst position residual divided by its tolerance) • position_ratio ≤ 1e-3 → margin = 1.0 (the residual is at least 1000× below the tolerance) • position_ratio = 1 → margin = 0.0 (exactly at the tolerance) evidence = min(1, (vertex_count - dof) / (2 × dof)) • plane with 4 vertices → evidence = 1.0 • cylinder with 8 vertices → evidence = 0.3 • cylinder with 15 vertices → evidence = 1.0 separation = min over rivals of: 1 - (my_normal_error / rival_normal_error) • no rivals → separation = 1.0 • a rival with the same error → separation = 0.0

The full formula:

(0.6 + 0.39 × position_margin) × (0.5 + 0.5 × evidence) × (0.6 + 0.4 × separation)

The possible range: 0.18 to 0.99

For unresolved:

confidence = 0.5 + 0.45 × clip(log10(violation) / 2, 0, 1) violation = max(position_ratio, normal_ratio) • violation = 10 → confidence ≈ 0.73 • violation = 100 → confidence ≈ 0.95

The further the closest candidate is from its tolerance, the surer we are that the segment really is not a primitive.

The closest candidate: a cylinder with vertex RMS = 18% of the segment's size.
The tolerance is 0.1%, so it misses by a factor of 180.
The quadric diagnostic shows the vertices lie on an ellipsoid with semi-axes 4, 2.5, 1.5 (residual 2.7e-8), which is an unsupported quadric.

The closest candidate: a cone with vertex RMS = 11% and normals off by 22°.
No primitive fits, and no general quadric either (residual 30%).
Result: unresolved.

🔧 API

from fitpipeline import classify_segment, load_mesh_segments mesh = load_mesh_segments("assignment/data", "mesh_02") record = mesh.segments[0] # the cylinder result = classify_segment(record) print(result.kind) # "primitive" print(result.primitive_type) # "cylinder" print(result.confidence) # 0.99 print(result.reason) # "cylinder: vertex RMS 9.6e-09..." print(result.best) # the chosen Candidate print(result.candidates) # every candidate that was evaluated

__main__.py CLI: python -m fitpipeline data/ output.json
🎯 The bottom line:
The criteria ensure that only good fits are accepted.
The normals separate primitives that the vertices cannot.
The simplest type wins, and the confidence reflects the quality of the decision.
